# Задачи, вкладки и группы

Читать при начале/продолжении задачи, выборе личной вкладки, изменении состава группы и завершении. Содержание: контекст → принадлежность → конвейер → закрытие → приватный режим.

## Контекст задачи

`start_task` сохраняет название, цель, область и основание разрешения до открытия/чтения. Запись не даёт полномочий сама по себе. Повтор с совпадающим контекстом возвращает существующее состояние, но не возобновляет paused/completed. Конфликт исправляется через явное `record_task_progress change:context`, а не новый ID. Старый журнал без title требует обновления контекста; группа без журнала — нового контекста её задачи, не выдуманной истории.

При продолжении: `get_task_progress`, при необходимости `list_tasks`, затем `restore_task` нужной задачи. Paused позволяет проверять прежние исходы, но не планировать новые мутации. Название новой группы задаётся title. Переименование существующей группы пользователем сохраняется; обновление контекста не переименовывает её автоматически.

## Принадлежность и личные вкладки

Единица принадлежности — зарегистрированная группа, не её имя, URL или окно. Пользовательская вкладка, помещённая внутрь рабочей группы, входит в задачу; это не расширяет цель и разрешения на действия. Вкладка вне группы, даже в том же окне, автоматически не присоединяется. Перенос всей группы и переименование сохраняют связь. Перенос вкладки за пределы группы исключает её из конвейера: прекрати действия и повторы, не переприсоединяй автоматически.

Для личной вкладки нужны прямое указание работать именно в ней и временная `attach_tab` с точным URL. «Открой сайт» не означает «используй мою уже открытую вкладку». При неопределённости принадлежности считай её личной. Открытие в указанном личном окне допускает `window_id`, но не разрешает перенаправление/закрытие остальных вкладок. Разрешение личной вкладки не становится постоянной привязкой для восстановления.

`list_tabs` — моментальный список метаданных. Перед решением о текущей/передней вкладке обнови его; `active` относится к окну, `foreground` и `window_focused` помогают определить видимость. Разрешённую фоновую вкладку читай по ID без обязательной активации. `activate_tab` используй, когда пользователь просит показать её или экран необходим для согласованного действия. Не возвращай фокус вопреки ручному переключению пользователя.

## Конвейер и восстановление

| Событие/состояние | Решение |
|---|---|
| Вкладка открыта в рабочей группе | Учесть в текущем составе |
| Вкладка отдельно закрыта или вынесена из группы | Исключить её, не восстанавливать автоматически |
| Окно закрыто с оставшимися вкладками | Сохранить последний состав; не возвращать ранее закрытые отдельно вкладки |
| Открытая зарегистрированная группа найдена | Сверить фактическое состояние, продолжить |
| Привязка есть, группа unavailable/closure_unknown | Попросить открыть сохранённую группу через Chrome |
| Пользователь открыл сохранённую группу с новым ID | Явная `task_group bind`; previous_group_id заменяет недоступную привязку |
| Пользователь поручил восстановить копией | `task_group copy`, новая группа из последнего доступного состава |
| Привязки нет | Создать группу для продолжения задачи; ссылки из чата использовать только когда нужны, не восстанавливать всю историю |
| Пользователь подтвердил удаление закрытой группы | `task_group forget` убирает запись, не выполняет действие Chrome |

Публичный API показывает открытые группы, не сохранённое меню Chrome. Отсутствие открытой группы не доказывает удаления. Не присваивай группу по имени/совпадению адресов. Копирование — попытка восстановления, не точная реконструкция: сохранены origin/path, без query/fragment, ввода, прокрутки и состояния приложения. Максимум 20 вкладок для копии. При `copy_pending`/неизвестном исходе проверь созданные вкладки, не повторяй автоматически.

История переходов и закрытых вкладок не накапливается в Brodex. Слепок — текущий состав рабочей группы; `sync_task_history` отключена. Не дописывай историю URL в рабочую папку. Пользовательские группы и личные вкладки не копируй в реестр постоянного восстановления.

## Закрытие и удаление

Для отдельной отработанной временной вкладки задачи — `close_tab`. Личная присоединённая вкладка закрывается только по прямому поручению с `user_confirmed:true`. Значимые страницы для продолжения не закрывай по собственному предположению о завершении задачи.

Для явно завершённой пользователем задачи или поручения удалить группу: `restore_task` → `delete_task_group` с зарегистрированным group_id, точным expected_tab_ids, mode, устойчивым request_id, user_confirmed:true. Команда разгруппировывает, сверяет исходные вкладки/окно/адреса, закрывает их и проверяет удаление привязки. Вручную исправлять конвейер после успешного выполнения не нужно. Закрытие окна и последовательные close_tab не заменяют эту команду.

`ungroup_task_group` оставляет вкладки открытыми и делает их личными. После отдельного поручения разгруппировать нельзя автоматически закрывать или присоединять их заново. При частичном исходе обеих команд проверяй stage, open_tab_ids и pending_operation. Не повторяй с новым ID. Для закрытой сохранённой группы сначала требуется открытие пользователем и явная привязка. `saved_group_deleted:unknown` не выдавай за программную проверку сохранённого меню.

## Режим и разрешения

Normal — обычный профиль, включая его cookies и автоматический вход; отдельное окно не является отдельной сессией авторизации. Incognito выбирай по поручению или когда задача требует не использовать обычную сессию/не сохранять посещения в её истории. Объясни самостоятельный выбор; при конфликте с требуемым входом уточни. `INCOGNITO_NOT_ALLOWED` требует разрешения расширению в Chrome, не подмены режимом normal.

Приватные окна одного профиля могут делить приватную сессию. Инкогнито не скрывает IP и не удаляет явно скачанные файлы. Не очищай cookies и не закрывай чужие окна ради «чистой сессии». Наблюдаемый MCP рассчитан на один подключённый профиль; не обещай выбор профилей без инструмента.
