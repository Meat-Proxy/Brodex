# Каталог команд Brodex

Полный перечень команд реализованного MCP. Это карта возможностей, не копия схемы и не подтверждение обновления текущего подключения. Перед вызовом используй фактическую схему доступного инструмента: она задаёт аргументы, перечисления и обязательные поля. Политика разрешений и последовательность задаются основным навыком и справочником операции. Новая техническая возможность не расширяет разрешение пользователя.

Содержание: подключение → задачи/группы → журнал → страницы → файлы → служебное хранение. Имена без префикса `mcp__brodex__`. Режим задаётся явно там, где он есть в схеме; остальные команды выводят его из проверенной вкладки/задачи.

Для отдельных манипуляций: `action_v2` — capabilities, prepare, control, retry, execute. Явные методы dom/dom_pointer/coordinate; точная цель, одноразовые исключения объекта/свойства, без быстрого повтора. Проверять execution и verification, а не только status. [Процесс и восстановление](recovery.md#протокол-action_v2). Старые команды подготовки ниже — совместимый API.

## Подключение, готовность и управление работой

| Команда | Назначение и существенные условия | Проверка результата |
|---|---|---|
| `status` | Проверить независимую native-связь, версию и разрешение инкогнито | connected не доказывает готовность конкретной страницы |
| `check_ready` | Ограниченный read-only опрос отклика main frame и стабильности viewport по tab_id/expected_url | Не подтверждает готовность приложения, не продлевает snapshot |
| `browser_work` | begin/end/status одной разрешённой вкладки и режима; begin требует expected_url | После begin новое наблюдение; end освобождает принадлежащий сеанс |
| `browser_task_control` | status/stop/resume вне занятой очереди; task_id, mode, до 20 tab_ids | cleanup и текущий этап; stop не откатывает отправленное |
| `get_diagnostics` | Ограниченные события расширения, limit/after_id | Содержит причины/этапы, не полный журнал Chrome |

Подробнее: [восстановление](recovery.md).

## Задачи, группы и вкладки

| Команда | Назначение и существенные условия | Проверка результата |
|---|---|---|
| `start_task` | Сохранить title/goal/scope/authorization_ref до браузерной работы; устойчивые task_id/request_id, mode | Успешная запись; не открывает вкладки и не выдаёт разрешение |
| `list_tasks` | Найти зарегистрированные задачи/привязки | Не является историей всех посещений |
| `restore_task` | Сверить текущую привязку задачи и доступность группы | Не открывает пропавшие вкладки и не ищет совпадения URL |
| `list_tabs` | Свежие ID/URL/режимы и признаки активного окна | Метаданные на момент вызова, не разрешение читать личное содержимое |
| `list_tab_groups` | Список открытых групп Chrome | Не список сохранённых закрытых групп |
| `open_tab` | Открыть URL в группе задачи после start_task; title задаёт имя; window_id только по указанию личного окна | Проверить ID, режим, URL и загрузку; неизвестный исход не повторять под новым ID |
| `activate_tab` | Показать разрешённую вкладку по точному expected_url и mode | active/focused; не изменяет принадлежность |
| `attach_tab` | Временное разрешение конкретной личной вкладки; task_id, URL и user_confirmed | Не постоянное восстановление; restore_record_id устарел |
| `close_tab` | Закрыть отдельную вкладку задачи; личная требует прямого поручения | Проверить фактическое закрытие; не заменяет удаление группы |
| `rename_group` | Переименовать зарегистрированную группу задачи | Имя не устанавливает принадлежность |
| `task_group` | bind — явная привязка открытой группы; forget — удалить запись; copy — порученная копия недоступной группы | Сверить фактическую привязку/вкладки; copy максимум 20, unknown без автоповтора |
| `delete_task_group` | Удалить открытую рабочую группу вместе с точным expected_tab_ids: разгруппировать → сверить → закрыть | stage, pending_operation, open_tab_ids и удаление привязки; сохранённое меню API не проверяет |
| `ungroup_task_group` | Разгруппировать точный состав и оставить вкладки открытыми | Вкладки становятся личными; не закрывать автоматически |
| `watch_tab_group` | start/read/stop ограниченного наблюдения; scope group или new_groups до открытия | Кандидаты/потери событий; не доказательство принадлежности или сохранённого восстановления |
| `sync_task_history` | Отключённый совместимый endpoint | Возвращает disabled; новую историю URL не пишет |

Подробнее: [задачи и вкладки](tasks-tabs.md). Наблюдение групп — память на 10 минут, 100 событий, до 8 новых групп; учитывай dropped/candidates_dropped/correlation_dropped/unresolved_events, останови watch после диагностики.

## Журнал прогресса

| Команда | Назначение и существенные условия | Проверка результата |
|---|---|---|
| `get_task_progress` | Прочитать контекст, revision, операции; при необходимости operation_id/history | Исходное состояние перед продолжением/восстановлением записи |
| `record_task_progress` | create/context/state/operation/action; expected_revision и request_id | Проверить ok и возвращённую revision; запись не исполняет действие |
| `record_task_progress_chain` | 1–20 зависимых записей одной задачи, начальная revision, ID каждого шага | Неатомарна: committed_steps, failed_step, last_confirmed_revision |

Подробнее: [журнал](workflow.md).

## Чтение, навигация и ввод

| Команда | Назначение и существенные условия | Проверка результата |
|---|---|---|
| `read_page` | Читать страницу/группу для действий либо отдельный read-only DOM-каталог через catalog; [выбор режима](page-actions.md#каталог-dom-объектов). | Обычное чтение: coverage/groups/truncated, новый snapshot_id. Каталог: coverage/sections, observation_id/ref; для действия — prepare_action.catalog_target, для AX — catalog.ax:true. Само чтение не заменяет и не продлевает action snapshot. |
| `read_page_code` | Очищенный DOM страницы или HTML/CSS/предки цели из свежего наблюдения | computed/coverage/усечение; не исходники JS и не разрешение исполнить код |
| `navigate` | goto/back/reload рабочей вкладки, уникальный request_id, активный browser_work | Новый фактический URL и новое наблюдение |
| `act` | click, fill, select, set_checked, scroll, hover по DOM; hover_at/click_at/wheel_at по подготовленному кадру. DOM-клик может доставляться мышью — [правила](page-actions.md#наблюдение-и-выбор-метода) | dispatched ≠ успех; value_matches, observation, wait_after и новое чтение |
| `wait_for` | Необязательный frame_id для ожидания внутри iframe;  ready/text/element/state/all/any; ограниченный timeout и при необходимости stable_ms | matched только в пределах полного покрытия; timeout не доказывает неуспеха действия |
| `screenshot` | Необязательный frame_id для PNG выбранного iframe;  Исходный обзорный PNG разрешённой вкладки с активным browser_work, без уменьшения/пересжатия | Просмотреть размеры/содержимое; не разрешает click_at напрямую. DOM-мутации возвращаются как capture_diagnostic; документ/viewport/прокрутка могут отменить обзор — visual-actions.md |
| `wait_stable` | Дождаться устойчивости наблюдаемой DOM-цели; необязательный timing | matched и фактические интервалы; затем новое наблюдение, старый снимок аннулирован |
| `prepare_operation` | 2–20 checkbox/Ctrl-шагов из общего обзора; цели и контекст до ввода | Просмотреть весь контрольный PNG, before/desired, snapshot_id и image_sha256 |
| `execute_operation` | Последовательно исполнить просмотренный план с проверкой каждого шага; defaults не требуют параметров | Подтверждённый префикс и статусы остальных; unknown/отказ не повторять |
| `inspect_operation` | Прочитать метаданные серии без исполнения и возобновления | Сверить со страницей; отсутствие записи не доказывает отсутствие эффекта |
| `inspect_snapshot_changes` | Прочитать сохранённый индекс DOM-изменений за интервал обзора, offset/limit, необязательный element_ref | Различать journal_coverage, response_coverage и target_coverage; не обновляет snapshot и не разрешает ввод |
| `prepare_action` | Общая подготовка DOM, мыши, клавиатуры, переноса, серии, файла или навигации без исполнения; DOM-цель также принимается через catalog_target вместо snapshot_id/element_id | Просмотреть контроль; сохранить preparation_id, snapshot_id, control_token; для новой обычной попытки использовать новый request_id по [правилам восстановления](recovery.md#сначала-установи-исход) |
| `execute_prepared_action` | Однократно исполнить сохранённую команду по просмотренному контролю без замены параметров | Проверить результат; неизвестный или частичный исход не повторять |
| `retry_preparation` | Один быстрый повтор подготовки; после отказа — рекурсивный повтор с исключениями последнего отчёта | Просмотреть новый контроль; исполнение остаётся отдельным шагом |
| `prepare_click` | Выбрать точку и 1–8 значимых областей по обзору; получить маскированный контрольный PNG | Просмотреть новый кадр, использовать новый snapshot_id/prepared_point |
| `prepare_retry` | Полный отказ → анализ в чате → новый обзор или DOM-чтение → сообщение о выборе повтора; failure_id, change_ids и reason без замены команды | Просмотреть контроль: PNG для координат, DOM-объект для DOM; сохранить retry_id, snapshot_id и image_sha256 либо control_token |
| `execute_retry` | Точный повтор сохранённой команды после просмотра контроля; одноразовые исключения | Проверить результат; при новом отказе полный отчёт и новый цикл по recovery.md |
| `mouse_click` | Подготовленный left/right с Shift/Ctrl/Alt | Проверить эффект; нативное контекстное меню не управляется |
| `press_key` | Одна поддержанная клавиша/комбинация в проверенном фокусе наблюдаемого документа и его поддержанных вложений | Проверить фокус и эффект; не горячие клавиши Chrome/ОС |
| `drag` | ЛКМ: нажать, переместить, отпустить в основном документе по просмотренному обзору | Обе точки видимы, проверить фактическое перемещение; частичный исход не откатывать вслепую |

Подробнее: [страница](page-actions.md), [тайминги ожиданий](page-actions.md#управление-таймингами-операций), [визуальные действия](visual-actions.md). Наличие параметра в схеме не означает, что экспериментальный сценарий включён в рабочую политику.

## Скачивание, сохранение и передача файлов

| Команда | Назначение и существенные условия | Проверка результата |
|---|---|---|
| `prepare_download_attempt` | Подготовить процесс получения файла или следующий step_id в том же attempt_id | Предыдущий результат установлен и загрузки проверены; повтор ID не перевооружает шаг |
| `execute_download_attempt` | Одно действие подготовленного шага: click/click_at/download_file | Не дублировать отдельным act; проверить страницу и inspect |
| `record_download_step_outcome` | Записать наблюдаемый результат шага: форма, формирование, готовность, загрузка или отказ | Только после inspect и проверки страницы; unknown блокирует продолжение, запись не доказывает источник файла |
| `inspect_download_attempt` | Сверить связанные загрузки и отдельные кандидаты, при необходимости window_start | Не считать кандидатов принадлежащими задаче автоматически |
| `list_download_attempts` | Найти прошлые попытки текущей задачи перед продолжением | Проверить неизвестные исходы прежде новой попытки |
| `confirm_download_source` | Связать конкретный download_id после проверки источника; source_verified:true | Связь с сайтом и точным файлом, не только время/имя |
| `download_status` | Состояние конкретного ID: bytes/state/exists/path/danger | Завершение передачи не заменяет проверки содержимого |
| `download_history` | Недавние записи Chrome в явном режиме и интервале до 10 минут; прямому вызову указать task_id | Не назначены задаче; possibly_truncated требует сужения |
| `download_file` | Прямая загрузка точного наблюдаемого HTTP(S)-адреса | Для новой попытки предпочитать через execute; возвращённый ID не означает завершение |
| `save_page` | Явно сохранить видимый текст страницы в статический .htm | Проверить download_id/файл; не полный архив сайта |
| `watch_downloads` | Совместимое пассивное наблюдение до действия сайта | Сам не скачивает; устойчивый request_id, результат — watch_id |
| `list_downloads` | До 100 кандидатов после начала watch текущей задачи | Кандидат не доказывает владельца |
| `bind_task_workspace` | Закрепить абсолютную папку чата-владельца для разрешённого переноса | Не менять чужую существующую привязку и не брать текущий cwd другого чата |
| `collect_download` | Перенести один завершённый безопасный проверенный файл при отдельном разрешении | Точный expected_filename, content_verified/user_confirmed; хеш копии до удаления исходника |
| `upload_file` | Назначить один разрешённый файл видимому input из свежего DOM | Может сразу передать сайту; assigned ≠ успех импорта |
| `upload_via_chooser` | Нажать наблюдаемую кнопку и перехватить один main-frame выбор файла до 8 секунд | Не нажимать отдельно заранее; проверить сайт, timeout не исключает эффект |

Подробнее: [скачивание](download-policy.md), [передача сайту](upload-policy.md).

### Наведение без нажатия

`act hover` — физическое наведение по guarded DOM element_id; карточки, подсказки, меню. `act hover_at` — наведение в просмотренную область по prepared snapshot_id/x/y после prepare_click, без нажатий. До движения сохраняются проверки цели; после — чтение результата или wait_after. См. [DOM](page-actions.md#самостоятельное-dom-наведение) и [координаты](visual-actions.md#самостоятельное-координатное-наведение).
