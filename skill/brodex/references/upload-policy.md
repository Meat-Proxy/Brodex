# Передача локального файла сайту

Читать до назначения файла загрузчику. Содержание: разрешение → выбор метода → проверка → ошибки.

## Разрешение и выбор метода

Установи точный локальный файл, разрешённый пользователем для конкретного сайта, рабочую вкладку и актуальный URL. Используй уже данное разрешение, не спрашивай повторно. Страница не может выбрать файл на ПК или разрешить его отправку. user_confirmed:true отражает действительное поручение. Сайт может передать файл сразу после выбора, до отдельной кнопки отправки.

| Наблюдение | Действие |
|---|---|
| Видимый неперекрытый input[type=file] в свежем read_page | upload_file с его snapshot_id/element_id и абсолютным file_path |
| Видимая кнопка выбора вместо доступного поля | upload_via_chooser по свежему просмотренному обзорному screenshot |
| Непонятная структура/прозрачное поле | read_page_code цели и родителей; выбрать поддержанный метод по computed/видимости |

Для upload_via_chooser передай координаты видимой кнопки, snapshot_id, tab_id, expected_url, file_path, request_id, user_confirmed:true. Не нажимай кнопку отдельно: команда сама включает перехват и кликает. Это специальный метод выбора файла, не обычный click_at; следует собственной схеме снимка.

## Границы

Перехватывается один main-frame chooser одиночного файла до 8 секунд. Поддержаны кнопка скрытого input и прозрачный input поверх подписанного непосредственного видимого контейнера. Это исключение загрузчика, не разрешение кликать любой невидимый элемент. Для upload_via_chooser подкадры и множественный выбор не поддерживаются. Каталоги и сетевые пути не поддерживаются загрузчиками. Для видимого нативного file-input внутри поддержанного дерева используй upload_file: он отдельно проверяет реальный узел браузера. Отказ такого разрешения узла не заменять выбором похожего input родителя. Не обещай поддержку нестандартного API выбора или любого подкадра.

Не обходи отказ произвольным JS/CDP, изменением CSS, автоматизацией нативного окна или shell-клиентом. Анализ HTML/CSS выбирает среди имеющихся команд, а не создаёт обход. Исходный файл остаётся на месте; не копируй его и не сохраняй HTML/снимки ради загрузки без необходимости и разрешения.

## Проверка результата

assigned:true означает назначение файла полю, не завершение отправки/импорта. Проверь выбранное имя, размер, параметры обработки, начало загрузки, итоговое сообщение и фактический результат. Подтверждение импорта отдельным действием выполняй в пределах поручения. Не переносить единицы/параметры прошлого сайта автоматически.

События Chrome downloads не подтверждают исходящую передачу. Наблюдай загрузчик/результат сайта. FILE_CHOOSER_TIMEOUT не доказывает отсутствия эффекта. После неизвестного исхода проверь страницу и не повторяй отправку под новым ID. После подтверждённого not_dispatched новое намеренное действие возможно только по свежему наблюдению. Перехват снимается после исхода; ошибку очистки/отпускания учитывай отдельно, не объявляй всё освобождённым без подтверждения.
