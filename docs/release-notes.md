Экспериментальный выпуск для установки и проверки на Windows с Chrome.

- Единый установщик для моста, навыка и MCP с учётом принадлежащих ему компонентов и безопасным удалением.
- Исправлены обработка скрытой AppData и проверка единственной записи MCP в Windows PowerShell.
- Постоянный ID расширения: мост регистрируется автоматически, передавать ID агенту не нужно.
- Общие инструкции выбирают опубликованный выпуск, включая предварительные, без привязки к текущему номеру.
- Публикация GitHub Release по тегу с проверкой согласованности версии.

**Установка:** скачай Source code (zip) ниже и следуй README.md или INSTALL-CODEX.md из этого архива. Codex устанавливает компоненты; пользователь загружает расширение вручную и включает доступ в инкогнито.

**Обновление старой установки:** при несовпадающем ID нужна однократная переустановка по README. Удаление сохраняет данные задач и резервные копии.

**Проверки и ограничения:** проверены идентичность расширения и запуск модулей с имитацией Chrome. Установщик ранее проверен в изолированной среде Windows PowerShell и PowerShell, включая нестандартный путь пользователя. Полный цикл новой установки с постоянным ID и живым Chrome ещё требует пользовательского теста. Проект остаётся экспериментальным; ограничения описаны в docs/validation.md.
