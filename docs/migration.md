# Сравнение с установленной версией 2.52

## Сохранено в исходниках

46 объявленных команд runtime, DOM-каталог и AX, action_v2, прежний API действий, группы и задачи, normal/incognito policy, native metadata, загрузка/скачивание через MCP. Совпадение списка команд не доказывает все возможные сценарии их исполнения.

Модули runtime скопированы без функциональных изменений. Отдельный загрузчик заменяет старый собранный background.js. DOM-каталог включён как динамически подгружаемый файл. Старые chunks, assets и картинки не включены.

## Новый минимальный интерфейс

Название/версия, состояние канала native host, переключатель brodexShowActions. Открытый native port не выдаётся за подтверждение доступности MCP. Переключатель использует прежний ключ настройки.

## Отличия, которые нельзя скрывать

- Старая штатная транспортная сессия Codex и связанные с ней UI не перенесены.
- Селектор окна старой сессии не перенесён; выбор окон через MCP и задачи остаётся в runtime.
- Кнопка восстановления разрешения старого транспорта не перенесена.
- Ручная панель скачивания по ссылке и обработчики старой оболочки не перенесены; это отдельный вопрос от скачивания через MCP.
- Подсказка о баннере отладки не перенесена. Поведение самого Chrome не менялось.
- Подключён утверждённый пользователем логотип: PNG 16/32/48/128 для Chrome, PNG 1024 и SVG как исходные ресурсы. Старые изображения не используются.
- Из навыка удалён раздел о прежнем штатном транспорте и фиксированный origin старой машины.

## Мост

Жёстко заданный origin заменён на allowed-origin.txt и в common.cjs, и в Launcher.cs. Генератор формирует согласованный native manifest и новые token/pipe; при наличии любого конфигурационного файла отказывается от изменения. Проверка origin сохранена. Генератор сам не изменяет реестр. scripts/setup.ps1 выполняет размещение, сборку launcher, явную регистрацию native host и откат кода. Первое обращение native host инициализирует только пустое хранилище.

## Ограничения проверки

Изолированные тесты не заменяют реальную установку. Первым живым прогоном проверить загрузку worker, открытие и восстановление группы, DOM/DOMмышь/координатный ввод, снимки, завершение работы, перезапуск и настройки. Известные проблемы восстановления группы после перезапуска Chrome автоматически не считаются исправленными.
