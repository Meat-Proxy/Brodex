# Проверки 2.53.0

Дата: 2026-11-21. Проверка разработчиком, не независимый аудит.

Проверены: загрузка standalone worker на имитации Chrome API и 46 объявленных команд; DOM-каталог, отношения, покрытие, инспекция, AX и маршрутизация; действия DOM/DOMмышь/координатные на искусственных страницах в отдельном headless Chrome; iframe, отказы и одноразовый контроль; реальные stdio MCP и native процессы с тестовым каналом; компилируемый Windows launcher, отклонение чужого origin, обмен сообщениями, первое создание native-хранилища; генерация конфигурации и защита существующей; Stage, обновление и Rollback на отдельном пути; размеры PNG и ссылки манифеста.

Не подтверждены: полная первая установка связки загруженного расширения, зарегистрированного native host и MCP в чистом пользовательском профиле; работа на втором компьютере; все сайты и разрешения.

Автоматическая загрузка отдельного Chrome for Testing прервалась сетевой ошибкой ECONNRESET. Установленный Chrome использовался для отдельных изолированных тестов страниц, что не заменяет тест установленного расширения. Публикация предназначена для внешнего тестирования.
# Проверка установщика после v2.53.0

Для 2.53.2: Install включает автоматический Register по ключу манифеста. Тест использует имитацию чтения/записи одного native-ключа реестра, а не прежнюю имитацию отсутствия ключа. Проверяются повторный Install без изменения token/pipe, отказ чужого явно переданного ID, отказ Stage при старой привязке до замены файлов, очистка регистрации при удалении. Отдельный tests/extension-identity.cjs закрепляет ключи и ID двух каналов и соответствие публичного манифеста. Полная живая установка 2.53.2 пока не проверена.

Для 2.53.1 добавлены регрессии: скрытый родительский каталог без Get-Item:Force в настройках сеанса; установка по умолчанию через переназначенный LOCALAPPDATA другого тестового пользователя с пробелом в пути; две записи MCP с проверкой точного имени в components.json и сохранения посторонней записи после удаления. Windows PowerShell 5.1 требует явного перечисления разобранного JSON перед фильтрацией и массива на стороне вызывающего кода. Тесты запускаются отдельно в Windows PowerShell 5.1 и PowerShell 7.

`powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/install.ps1` проверяет отдельную установку и реальный Codex CLI с изолированным CODEX_HOME, повторное подключение, сохранение учёта при Stage/Rollback, защиту изменённого/чужого навыка и удаление программы/MCP/навыка. Реестр native host в этом тесте представлен отсутствующим ключом; реальная регистрация и удаление ключа, живая связь нового расширения и второй компьютер этим тестом не подтверждаются. Синтетические артефакты остаются в отдельном соседнем install-test-* каталоге.
