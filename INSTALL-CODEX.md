# Установка Brodex агентом Codex

Эта инструкция применяется по просьбе пользователя установить Brodex. Для неё не нужен уже работающий MCP или навык Brodex. Windows, Chrome, Node.js 20+ и доступная команда Codex CLI обязательны. Не объявляй соединение рабочим только по успешной установке файлов.

1. Если пользователь не выбрал конкретную версию, открой [список Releases](https://github.com/Meat-Proxy/Brodex/releases) или API `https://api.github.com/repos/Meat-Proxy/Brodex/releases`. Выбери самый новый опубликованный выпуск по `published_at`, исключая черновики и **включая предварительные выпуски**. Не используй `/releases/latest`: он исключает pre-release. Зафиксируй `tag_name`, скачай ZIP этого тега и распакуй в отдельную папку. Читай `INSTALL-CODEX.md` именно из этого архива; инструкция и скрипты должны совпадать с выбранным выпуском. Если выпуска или этой инструкции нет, сообщи об этом; не переходи на `main` без явного запроса разработки. Проверь наличие Node, Chrome и `codex`. Если зависимости отсутствуют, сообщи конкретно какие; не выбирай сторонние загрузчики. Учитывай фактический CODEX_HOME пользователя. Стандартные пути определяются из LOCALAPPDATA и USERPROFILE текущего пользователя; не подставляй имя пользователя или диск из чужого примера.
2. Выполни из распакованной папки:

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1 -Action Install
   ```

   Это размещает мост и расширение в `%LOCALAPPDATA%\Brodex\App`, устанавливает навык в выбранный CODEX_HOME, регистрирует мост для постоянного ID из манифеста и добавляет MCP через официальный CLI. Повтор Install возобновляет настройку существующей установки, но не обновляет её код. Чужой или изменённый компонент сохраняется с явным отказом. Не удаляй его для обхода конфликта: сначала выясни происхождение и согласуй замену. Для нестандартных путей используй одинаковые `-InstallDir`, `-CodexHome`, при необходимости `-CodexCommand`.
3. Теперь попроси пользователя выполнить ровно этот ручной шаг:

   **Самостоятельно открой в Chrome `chrome://extensions`. Включи «Режим разработчика», нажми «Загрузить распакованное расширение» и выбери `%LOCALAPPDATA%\Brodex\App\extension`. Затем открой «Подробнее» у Brodex и включи «Разрешить использование в режиме инкогнито». Сообщи «установлено». Передавать ID не нужно.**

   Подставь фактический путь, если выбран другой каталог. Не пытайся автоматически устанавливать расширение, изменять профиль Chrome или его политики. На время ожидания освободи активные подключения управления браузером, если они использовались.
4. После подтверждения проверь доступность MCP Brodex; если текущий клиент не подхватил его, попроси переподключить MCP/начать новый чат. Проверь `status` через реально доступный инструмент. При отсутствии соединения попроси перезагрузить расширение и проверь снова. Различай: файлы установлены; MCP настроен; мост зарегистрирован; живая связь проверена. Известный ID и сообщение «установлено» сами по себе не подтверждают соединение.

## Обновление и удаление

Переход с 2.53.1 и более ранних сборок меняет ID: используй описанную в README однократную переустановку, не переписывай allowed-origin.txt вручную.

Обновление: завершить работу Brodex, остановить MCP и закрыть Chrome; выполнить Stage из нового выпуска с прежним InstallDir, затем Connect для обновления принадлежащего установщику навыка. Код и реестр компонентов сохраняются вместе; Rollback возвращает код, после него Connect согласует навык.

Удаление: по прямой просьбе пользователя остановить MCP/Brodex и удалить расширение вручную в Chrome, затем из сохранённого распакованного комплекта выполнить `setup.ps1 -Action Uninstall` с теми же путями. Удаляются проверенные файлы приложения, запись MCP, установленный навык и регистрация native host. Изменённые/неучтённые компоненты вызывают отказ. Повтор после частичного удаления проверяет оставшееся состояние.

Данные задач и резервные версии пока сохраняются и явно перечислены как оставшиеся категории. Полная очистка данных и резервных копий ещё не реализована. Не удаляй весь `%LOCALAPPDATA%\Brodex` или CODEX_HOME. История Codex и пользовательские скачивания вне ответственности деинсталлятора. Старые ручные установки без учёта автоматически не присваиваются.
